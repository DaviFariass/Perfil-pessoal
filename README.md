## 🛠️ Minha Stack & Habilidades

O projeto foi construído utilizando as tecnologias base da Web, estruturado em um layout moderno de página única (*Single Page*) com suporte a *Dark Mode*:

- **HTML5:** Estrutura semântica e acessível.
- **CSS3:** Estilização responsiva (Flexbox/Grid), variáveis nativas e efeitos de transição modernos.
- **Identidade Visual:** Favicon minimalista exclusivo integrado ao design.

### Linguagens e Ferramentas que venho explorando:
- **Linguagens:** Python, PHP, JavaScript, Java.
- **Bancos de Dados:** SQL (MySQL) e NoSQL (MongoDB).
- **Metodologias:** Práticas ágeis utilizando a metodologia Scrum.
